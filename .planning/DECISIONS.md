## Ideas considered and dropped

Recorded so they are not re-proposed.

- **Audio prompt injection through AssemblyAI's API MCP server.** True of any tool that returns untrusted text, and publishing an exploit is the wrong opening with the team. Could be raised privately later.
- **Census of public repos broken by API removals, plus an agent repair benchmark.** GitHub search counts are noisy and making strangers' repos runnable would eat the schedule. One seeded legacy-upgrade task (T4) keeps the useful part.
- **A second agent (Codex) for replication.** Dropped by the owner (decision 6). Later Codex became the measured agent instead (decision 32), not a replication.
- **A TLS-intercepting proxy for all wire capture.** Deferred; see Phase 2 Q2.
